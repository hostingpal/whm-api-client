# Sanitized live evidence

Files in this directory are generated by the explicitly opted-in
[live verification command](../../../tools/live-verify/README.md). They contain
structural paths/types, separate API/payload/probe outcomes and exact provenance.
They contain no raw response payloads or request credentials.

Each file establishes observations only for its recorded operation, route,
server version, code revision and contract. Empty lists do not establish item
fields. The generated coverage table and independent offline tests remain separate
claims. Re-run a reviewed recipe when its code or contract changes; historical
evidence is not silently promoted to the new revision.
