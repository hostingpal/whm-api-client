These profiles are synthetic fixtures for the capability-profile v1 contract.
No server was contacted to produce them. Names preserve exact case and namespace;
they do not predict how any particular server advertises its functions.

A successful profile records only two allowlisted observations. A partial profile
records successful version discovery and failed inventory capture; its empty
inventory is not a claim that the server advertises no functions. A failed
profile makes no successful inventory claim. UAPI enumeration remains unavailable
and direct UAPI authentication remains unverified in every fixture.

Real captures default to the ignored `.cache/api-map/capability-profile.json`.
Do not add credentials or real server profiles to these public fixtures.
