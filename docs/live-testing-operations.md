# Live-test operation groups

Generated from the reviewed API map (`docs/api/map.sha256`) and the explicit
lists in [live-testing.md](live-testing.md); every pinned operation appears once.
Unlisted operations fall back to the map risk class: read-only, UAPI mutation
(account-scoped) or WHM mutation (server-wide). `Client` shows whether master
has a typed method, an explicit exclusion or neither (use generic `call()`);
refresh it with `php tools/live-testing/refresh-operations-client.php`.

| Group | Operations |
| --- | ---: |
| Read-only (any time) | 513 |
| Account-scoped mutations (designated or disposable test accounts, any time) | 382 |
| Server-wide mutations (inside a snapshot window) | 307 |
| Lockout or version-changing (last in a snapshot window) | 37 |
| External effects not undone by a restore (owned or synthetic targets only) | 66 |
| Possibly paid (excluded until the owner confirms they are free) | 8 |
| Costs money (excluded) | 10 |
| Total | 1323 |
