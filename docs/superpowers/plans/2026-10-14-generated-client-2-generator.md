# Generated Client, Plan 2: Overlay and Generator Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Extend `tools/api-map` with an evidence-bound overlay, an effective-contract builder and a deterministic PHP generator (`overlay validate`, `generate php [--check]`).

**Architecture:** Three new Go packages. `overlay` loads and validates `docs/api/overlay/**` against a published JSON schema. `effective` applies the overlay to the canonical map (`model.Map`): groups (UAPI module / WHM `x-tagGroups`), method and parameter names, HTTP method, parameter encodings, response type specs (converted from OpenAPI schemas and corrected by overlay paths), unwrap, docs and exclusions. `phpgen` renders group classes, spec classes, accessor traits and a coverage summary that match plan 1's spec format and the repository's PHPCS rules. The CLI writes the files atomically or, with `--check`, fails when committed output differs.

**Tech Stack:** Go 1.24 (no newer language features; CI uses `setup-go` with `go-version: '1.24'`), `github.com/santhosh-tekuri/jsonschema/v6` through the existing `internal/schema` package, existing `model`, `openapi` and `source` packages.

**Spec:** `docs/superpowers/specs/2026-10-14-generated-client-design.md` (sections "Public API surface", "Overlay", "Effective contract and generator", "Generated PHP and the runtime engine").

**Prerequisite:** Plan 1 is merged into `master` (the PHP spec format below is its contract). Work on a branch `feat/generated-client-generator` from up-to-date `master`.

## Global Constraints

- Go code must be `gofmt`-clean and pass `go vet ./...`; CI also runs `go test ./...` with `GOPROXY=off GOSUMDB=off` on Go 1.24.
- Output is deterministic: identical map, overlay and generator produce byte-identical files (sorted groups, operations, fields and imports).
- Generated PHP must satisfy `phpcs.xml.dist` (PSR-12, trailing commas in multi-line arrays/calls/declarations, alphabetically sorted and used imports, ≤120-character lines) and PHPStan maximum level.
- Generated files carry the marker `Generated by tools/api-map from the pinned API map and docs/api/overlay; do not edit.` and are never edited by hand.
- Every overlay correction and exclusion carries evidence (`kind` `doc` or `live`, `version`, `date` `YYYY-MM-DD`, `note`).
- Method names: mechanical camelCase of the function name; every function without a separator, with a leading underscore, or containing `/` needs an explicit overlay `name`.
- WHM groups are the documented `x-tagGroups` entries and need an overlay `accessor`; UAPI groups are modules (accessor/class derived mechanically).
- Read-only operations default to GET; mutating, unknown-risk and secret-bearing operations default to POST; a GET override for a secret-bearing operation is an error.
- Reserved handle names (`call`, `responseMeta`, `username`, `isBridged`) are never group accessors.
- Routine checks stay offline; this plan never contacts the live server.

## Review Focus

- **OpenAPI `$ref` cycles and deep schemas.** Recursive component schemas must terminate (depth 8, cycle detection) and yield `mixed`, not loop or panic. Pinned in Task 3 (`TestSpecForStopsAtCycles`).
- **`*/` inside documentation text.** cPanel descriptions can contain `*/`, which would close a PHP docblock early. Pinned in Task 5 (`TestDocEscapesCommentTerminators`).
- **Field names that are not PHP identifiers.** Response fields such as `MXCHECK-domain` or `0` must render as quoted PHPStan shape keys. Pinned in Task 5 (`TestShapeQuotesNonIdentifierKeys`).
- **Stale generated files.** When an operation or group disappears from scope, its previously generated file must be reported by `--check` and removed on write; hand-written files without the marker are never touched. Pinned in Task 7 (`TestGeneratePHPRemovesOnlyStaleGeneratedFiles`).
- **Overlay entries that point at nothing.** An overlay parameter, correction path or operation ID that the map does not document must be a reported problem, not silently ignored. Pinned in Task 4 (`TestBuildReportsUnknownOverlayTargets`).

### PHP output contract (from plan 1)

Spec constant keys: `function`, `module` (UAPI only), `method` (`GET`/`POST`), `outcome` (`flag`/`unchecked`), `params` (PHP name → `['name' => wire, 'encoding' => 'scalar'|'bool'|'repeat'|'numbered']`), `returns` (type spec or `null`), optional `unwrap`. Type spec keys: `type` (`string`, `int`, `number`, `bool`, `flag`, `mixed`, `list`, `map`, `object`, `union`), optional `nullable`, `accept`, `preserve`, `items`, `values`, `fields`, `required`, `anyOf`. Generated group constructors take `Closure $run` and call `($this->run)(<Class>Spec::<CONST>, [<php name> => $<php name>, ...])`. Generated traits call `$this->run(...)` on the handle.

// Package overlay loads the evidence-bound naming decisions and response
// corrections that turn the canonical API map into the generated client's
// effective contract. Group files live in docs/api/overlay/{uapi,whm}/*.json.
package overlay

import (
	"bytes"
	"encoding/json"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"sort"
	"unicode/utf8"

	"github.com/hostingpal/whm-api-client/tools/api-map/internal/schema"
)

// Config selects which operations are generated.
type Config struct {
	SchemaVersion string `json:"schema_version"`
	// Scope is "listed" (only operations named in group files) or "all".
	Scope string `json:"scope"`
}

// File is one group's overlay.
type File struct {
	SchemaVersion string               `json:"schema_version"`
	Family        string               `json:"family"`
	Group         string               `json:"group"`
	Accessor      string               `json:"accessor,omitempty"`
	Class         string               `json:"class,omitempty"`
	Description   string               `json:"description,omitempty"`
	Operations    map[string]Operation `json:"operations"`
	Path          string               `json:"-"`
}

// Operation holds per-operation decisions; zero values keep generator defaults.
type Operation struct {
	Name     string                `json:"name,omitempty"`
	Method   string                `json:"method,omitempty"`
	Outcome  string                `json:"outcome,omitempty"`
	Unwrap   string                `json:"unwrap,omitempty"`
	Void     bool                  `json:"void,omitempty"`
	Order    []string              `json:"order,omitempty"`
	Params   map[string]Param      `json:"params,omitempty"`
	Response map[string]Correction `json:"response,omitempty"`
	Notes    []string              `json:"notes,omitempty"`
	Exclude  *Exclusion            `json:"exclude,omitempty"`
	Probe    json.RawMessage       `json:"probe,omitempty"`
}

// Param renames, re-encodes or omits one documented parameter, keyed by wire
// name. Omitted parameters (aliases, wildcard patterns such as MXCHECK-*) stay
// reachable through call() and are left out of the generated signature.
type Param struct {
	PHP       string `json:"php,omitempty"`
	Encoding  string `json:"encoding,omitempty"`
	Sensitive *bool  `json:"sensitive,omitempty"`
	Omit      bool   `json:"omit,omitempty"`
}

// Correction changes the documented response type at one payload path.
type Correction struct {
	Type     string     `json:"type,omitempty"`
	Accept   []string   `json:"accept,omitempty"`
	Nullable *bool      `json:"nullable,omitempty"`
	Preserve bool       `json:"preserve,omitempty"`
	Required *bool      `json:"required,omitempty"`
	Add      *Spec      `json:"add,omitempty"`
	Evidence []Evidence `json:"evidence"`
}

// Spec is the JSON form of a type spec, used to declare undocumented fields.
type Spec struct {
	Type     string          `json:"type"`
	Nullable bool            `json:"nullable,omitempty"`
	Accept   []string        `json:"accept,omitempty"`
	Preserve bool            `json:"preserve,omitempty"`
	Items    *Spec           `json:"items,omitempty"`
	Values   *Spec           `json:"values,omitempty"`
	Fields   map[string]Spec `json:"fields,omitempty"`
	Required []string        `json:"required,omitempty"`
	AnyOf    []Spec          `json:"anyOf,omitempty"`
}

// Exclusion removes an operation from generation for a documented reason.
type Exclusion struct {
	Reason   string     `json:"reason"`
	Evidence []Evidence `json:"evidence"`
}

// Evidence binds a decision to documentation or a live observation.
type Evidence struct {
	Kind        string `json:"kind"`
	Version     string `json:"version"`
	Date        string `json:"date"`
	Note        string `json:"note"`
	Fingerprint string `json:"fingerprint,omitempty"`
}

// Set is a loaded overlay directory.
type Set struct {
	Config Config
	Files  []File
}

// Load reads config.json and every group file in deterministic order.
func Load(dir string) (Set, error) {
	var set Set
	raw, err := readLimited(filepath.Join(dir, "config.json"))
	if err != nil {
		return Set{}, fmt.Errorf("overlay config: %w", err)
	}
	if err := rejectDuplicateKeys(raw); err != nil {
		return Set{}, fmt.Errorf("overlay config: %w", err)
	}
	if err := strictDecode(raw, &set.Config); err != nil {
		return Set{}, fmt.Errorf("overlay config: %w", err)
	}
	if set.Config.SchemaVersion != "1.0" || (set.Config.Scope != "listed" && set.Config.Scope != "all") {
		return Set{}, fmt.Errorf("overlay config: schema_version must be 1.0 and scope listed or all")
	}
	for _, family := range []string{"uapi", "whm"} {
		paths, err := filepath.Glob(filepath.Join(dir, family, "*.json"))
		if err != nil {
			return Set{}, err
		}
		sort.Strings(paths)
		for _, path := range paths {
			file, err := loadFile(path)
			if err != nil {
				return Set{}, fmt.Errorf("%s/%s: %w", family, filepath.Base(path), err)
			}
			set.Files = append(set.Files, file)
		}
	}
	return set, nil
}

func loadFile(path string) (File, error) {
	raw, err := readLimited(path)
	if err != nil {
		return File{}, err
	}
	if err := rejectDuplicateKeys(raw); err != nil {
		return File{}, err
	}
	// Validate the original object before Go's case-insensitive struct
	// matching can accept schema-forbidden property names.
	var original any
	decoder := json.NewDecoder(bytes.NewReader(raw))
	decoder.UseNumber()
	if err := decoder.Decode(&original); err != nil {
		return File{}, err
	}
	if err := schema.Validate("overlay-v1.schema.json", original); err != nil {
		return File{}, err
	}
	var file File
	if err := strictDecode(raw, &file); err != nil {
		return File{}, err
	}
	file.Path = path
	return file, nil
}

func readLimited(path string) ([]byte, error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, err
	}
	defer f.Close()
	raw, err := io.ReadAll(io.LimitReader(f, (8<<20)+1))
	if err != nil || len(raw) > 8<<20 || !utf8.Valid(raw) {
		return nil, fmt.Errorf("invalid overlay input")
	}
	return raw, nil
}

func strictDecode(raw []byte, target any) error {
	decoder := json.NewDecoder(bytes.NewReader(raw))
	decoder.DisallowUnknownFields()
	if err := decoder.Decode(target); err != nil {
		return err
	}
	if decoder.More() {
		return fmt.Errorf("trailing overlay data")
	}
	return nil
}

func rejectDuplicateKeys(raw []byte) error {
	decoder := json.NewDecoder(bytes.NewReader(raw))
	decoder.UseNumber()
	if err := walkTokens(decoder); err != nil {
		return err
	}
	if _, err := decoder.Token(); err != io.EOF {
		return fmt.Errorf("trailing overlay data")
	}
	return nil
}

func walkTokens(decoder *json.Decoder) error {
	token, err := decoder.Token()
	if err != nil {
		return err
	}
	delimiter, ok := token.(json.Delim)
	if !ok {
		return nil
	}
	switch delimiter {
	case '{':
		seen := map[string]bool{}
		for decoder.More() {
			key, err := decoder.Token()
			if err != nil {
				return err
			}
			name, _ := key.(string)
			if seen[name] {
				return fmt.Errorf("duplicate key %q", name)
			}
			seen[name] = true
			if err := walkTokens(decoder); err != nil {
				return err
			}
		}
	case '[':
		for decoder.More() {
			if err := walkTokens(decoder); err != nil {
				return err
			}
		}
	}
	_, err = decoder.Token()
	return err
}

package overlay

import (

// Validate reports structural problems the JSON schema cannot express. Problems
// that need the API map (unknown operations, group membership, undocumented
// parameters) are reported by the effective builder.
func Validate(set Set) []string {
	var problems []string
	seen := map[string]string{}
	for _, file := range set.Files {
		name := filepath.Base(filepath.Dir(file.Path)) + "/" + filepath.Base(file.Path)
		inUAPIDirectory := filepath.Base(filepath.Dir(file.Path)) == "uapi"
		if inUAPIDirectory != (file.Family == "uapi") {
			problems = append(problems, name+": family does not match its directory")
		}
		if file.Family == "whm1" && file.Accessor == "" {
			problems = append(problems, name+": WHM groups need an accessor")
		}
		ids := make([]string, 0, len(file.Operations))
		for id := range file.Operations {
			ids = append(ids, id)
		}
		sort.Strings(ids)
		for _, id := range ids {
			if !strings.HasPrefix(id, file.Family+":") {
				problems = append(problems, name+": "+id+" is not a "+file.Family+" operation")
			}
			if other, duplicate := seen[id]; duplicate {
				problems = append(problems, id+" appears in "+other+" and "+name)
			}
			seen[id] = name
			op := file.Operations[id]
			if op.Exclude != nil && (op.Name != "" || len(op.Params) > 0 || len(op.Response) > 0 || op.Unwrap != "") {
				problems = append(problems, id+": excluded operations take no other settings")
			}
			if op.Void && op.Unwrap != "" {
				problems = append(problems, id+": void and unwrap are exclusive")
			}
		}
	}
	sort.Strings(problems)
	return problems
}

package effective

import (
	"regexp"
	"strings"
	"unicode"
)

var (
	separators = regexp.MustCompile(`[^A-Za-z0-9]+`)
	methodName = regexp.MustCompile(`^[a-z][A-Za-z0-9]*$`)
	className  = regexp.MustCompile(`^[A-Z][A-Za-z0-9]*$`)
)

// Words splits a name at separators and case boundaries; a run of capitals is
// one word unless its last capital starts a lowercase word (LangPHP -> Lang PHP,
// XMLHttp -> XML Http).
func Words(s string) []string {
	var words []string
	for _, part := range separators.Split(s, -1) {
		if part == "" {
			continue
		}
		runes := []rune(part)
		start := 0
		for i := 1; i < len(runes); i++ {
			previous, current := runes[i-1], runes[i]
			nextLower := i+1 < len(runes) && unicode.IsLower(runes[i+1])
			lowerToUpper := (unicode.IsLower(previous) || unicode.IsDigit(previous)) && unicode.IsUpper(current)
			acronymEnd := unicode.IsUpper(previous) && unicode.IsUpper(current) && nextLower
			if lowerToUpper || acronymEnd {
				words = append(words, string(runes[start:i]))
				start = i
			}
		}
		words = append(words, string(runes[start:]))
	}
	return words
}

func title(word string) string {
	lower := strings.ToLower(word)
	return strings.ToUpper(lower[:1]) + lower[1:]
}

// Camel returns lowerCamelCase.
func Camel(s string) string {
	words := Words(s)
	for i, word := range words {
		if i == 0 {
			words[i] = strings.ToLower(word)
		} else {
			words[i] = title(word)
		}
	}
	return strings.Join(words, "")
}

// Pascal returns UpperCamelCase.
func Pascal(s string) string {
	words := Words(s)
	for i, word := range words {
		words[i] = title(word)
	}
	return strings.Join(words, "")
}

// Constant returns UPPER_SNAKE_CASE.
func Constant(s string) string {
	return strings.ToUpper(strings.Join(Words(s), "_"))
}

// IsMethodName reports whether s is a valid generated method or argument name.
func IsMethodName(s string) bool { return methodName.MatchString(s) }

// IsClassName reports whether s is a valid generated class name.
func IsClassName(s string) bool { return className.MatchString(s) }

// maxDepth bounds schema expansion; deeper nodes become mixed.
const maxDepth = 8

type schemas struct {
	m     model.Map
	index *openapi.Index
}

func newSchemas(m model.Map) (schemas, error) {
	var index *openapi.Index
	var err error
	if len(m.Sources) == 0 {
		index, err = openapi.NewIndex(m.Documents)
	} else {
		index, err = openapi.NewBundleIndex(source.Bundle{Records: m.Sources, Documents: m.Documents})
	}
	return schemas{m: m, index: index}, err
}

func asObject(v any) (map[string]any, bool) {
	switch o := v.(type) {
	case model.Object:
		return o, true
	case map[string]any:
		return o, true
	}
	return nil, false
}

// follow resolves a $ref chain and returns the concrete object, the document it
// came from, and a cycle key for the last reference followed.
func (s schemas) follow(sourceID string, node any) (map[string]any, string, string, bool) {
	key := ""
	for range 32 {
		obj, ok := asObject(node)
		if !ok {
			return nil, sourceID, key, false
		}
		ref, isRef := obj["$ref"].(string)
		if !isRef {
			return obj, sourceID, key, true
		}
		resolved, err := s.index.Resolve(sourceID, ref)
		if err != nil || resolved.Origin.Pointer == nil {
			return nil, sourceID, key, false
		}
		sourceID = resolved.Origin.SourceID
		key = sourceID + "#" + *resolved.Origin.Pointer
		node = resolved.Value
	}
	return nil, sourceID, key, false
}

// specFor converts an OpenAPI schema node into a type spec.
func (s schemas) specFor(sourceID string, node any, depth int, seen map[string]bool) TypeSpec {
	obj, sourceID, key, ok := s.follow(sourceID, node)
	if !ok || depth > maxDepth || (key != "" && seen[key]) {
		return TypeSpec{Type: "mixed"}
	}
	if key != "" {
		next := make(map[string]bool, len(seen)+1)
		for k := range seen {
			next[k] = true
		}
		next[key] = true
		seen = next
	}
	spec := s.shape(sourceID, obj, depth, seen)
	if isNullable(obj) {
		spec.Nullable = true
	}
	return spec
}

func (s schemas) shape(sourceID string, obj map[string]any, depth int, seen map[string]bool) TypeSpec {
	if parts, ok := obj["allOf"].([]any); ok && len(parts) > 0 {
		return s.allOf(sourceID, parts, depth, seen)
	}
	for _, key := range []string{"oneOf", "anyOf"} {
		if options, ok := obj[key].([]any); ok && len(options) > 0 {
			union := TypeSpec{Type: "union"}
			for _, option := range options {
				union.AnyOf = append(union.AnyOf, s.specFor(sourceID, option, depth+1, seen))
			}
			return union
		}
	}
	if isFlagEnum(obj) {
		return TypeSpec{Type: "flag"}
	}
	switch typeName(obj) {
	case "string":
		return TypeSpec{Type: "string"}
	case "integer":
		return TypeSpec{Type: "int"}
	case "number":
		return TypeSpec{Type: "number"}
	case "boolean":
		return TypeSpec{Type: "bool"}
	case "array":
		item := TypeSpec{Type: "mixed"}
		if items, ok := obj["items"]; ok {
			item = s.specFor(sourceID, items, depth+1, seen)
		}
		return TypeSpec{Type: "list", Items: &item}
	}
	if props, ok := asObject(obj["properties"]); ok && len(props) > 0 {
		spec := TypeSpec{Type: "object"}
		for _, name := range sortedKeys(props) {
			spec.Fields = append(spec.Fields, Field{Name: name, Spec: s.specFor(sourceID, props[name], depth+1, seen)})
		}
		spec.Required = requiredNames(obj, props)
		return spec
	}
	if extra, ok := asObject(obj["additionalProperties"]); ok {
		values := s.specFor(sourceID, extra, depth+1, seen)
		return TypeSpec{Type: "map", Values: &values}
	}
	if typeName(obj) == "object" {
		return TypeSpec{Type: "map", Values: &TypeSpec{Type: "mixed"}}
	}
	return TypeSpec{Type: "mixed"}
}

func (s schemas) allOf(sourceID string, parts []any, depth int, seen map[string]bool) TypeSpec {
	merged := TypeSpec{Type: "object"}
	for _, part := range parts {
		spec := s.specFor(sourceID, part, depth+1, seen)
		if spec.Type != "object" {
			if len(parts) == 1 {
				return spec
			}
			return TypeSpec{Type: "mixed"}
		}
		merged.Fields = mergeFields(merged.Fields, spec.Fields)
		merged.Required = mergeNames(merged.Required, spec.Required)
	}
	return merged
}

// payload returns the documented success payload (WHM data, UAPI result.data),
// nil when the envelope documents none, and the operation object.
func (s schemas) payload(op model.Operation, v model.Variant) (*TypeSpec, map[string]any, error) {
	loc := v.OperationLocator
	if loc.Pointer == nil {
		return nil, nil, fmt.Errorf("%s: missing operation pointer", v.ID)
	}
	node, err := source.Pointer(s.m.Documents[loc.SourceID], *loc.Pointer)
	if err != nil {
		return nil, nil, fmt.Errorf("%s: %w", v.ID, err)
	}
	operation, ok := asObject(node)
	if !ok {
		return nil, nil, fmt.Errorf("%s: operation is not an object", v.ID)
	}
	responses, _ := asObject(operation["responses"])
	response, responseSource, _, ok := s.follow(loc.SourceID, responses["200"])
	if !ok {
		return nil, operation, nil
	}
	content, _ := asObject(response["content"])
	media, _ := asObject(content["application/json"])
	envelope, envelopeSource, _, ok := s.follow(responseSource, media["schema"])
	if !ok {
		return nil, operation, nil
	}
	props, _ := asObject(envelope["properties"])
	data, has := props["data"]
	if op.Family == "uapi" {
		if result, hasResult := props["result"]; hasResult {
			if resultObject, resultSource, _, ok := s.follow(envelopeSource, result); ok {
				resultProps, _ := asObject(resultObject["properties"])
				data, has = resultProps["data"]
				envelopeSource = resultSource
			}
		}
	}
	if !has {
		return nil, operation, nil
	}
	spec := s.specFor(envelopeSource, data, 0, nil)
	return &spec, operation, nil
}

// enumDoc renders a schema's enum as a PHPStan literal union, or "" when absent.
func (s schemas) enumDoc(sourceID string, node any) string {
	obj, _, _, ok := s.follow(sourceID, node)
	if !ok {
		return ""
	}
	values, ok := obj["enum"].([]any)
	if !ok || len(values) == 0 {
		return ""
	}
	parts := make([]string, 0, len(values))
	for _, value := range values {
		switch v := value.(type) {
		case string:
			parts = append(parts, "'"+strings.ReplaceAll(strings.ReplaceAll(v, `\`, `\\`), "'", `\'`)+"'")
		case fmt.Stringer:
			parts = append(parts, v.String())
		case float64, int:
			parts = append(parts, fmt.Sprint(v))
		default:
			return ""
		}
	}
	return strings.Join(parts, "|")
}

func typeName(obj map[string]any) string {
	switch t := obj["type"].(type) {
	case string:
		return t
	case []any:
		for _, item := range t {
			if name, ok := item.(string); ok && name != "null" {
				return name
			}
		}
	}
	return ""
}

func isNullable(obj map[string]any) bool {
	if nullable, ok := obj["nullable"].(bool); ok && nullable {
		return true
	}
	if types, ok := obj["type"].([]any); ok {
		for _, t := range types {
			if t == "null" {
				return true
			}
		}
	}
	return false
}

// isFlagEnum detects 0/1 enums, ignoring a null member of nullable enums.
func isFlagEnum(obj map[string]any) bool {
	values, ok := obj["enum"].([]any)
	if !ok {
		return false
	}
	found := map[string]bool{}
	for _, value := range values {
		if value != nil {
			found[fmt.Sprint(value)] = true
		}
	}
	return len(found) == 2 && found["0"] && found["1"]
}

func requiredNames(obj map[string]any, props map[string]any) []string {
	var names []string
	required, _ := obj["required"].([]any)
	for _, item := range required {
		if name, ok := item.(string); ok {
			if _, declared := props[name]; declared {
				names = append(names, name)
			}
		}
	}
	sort.Strings(names)
	return names
}

func sortedKeys[V any](m map[string]V) []string {
	keys := make([]string, 0, len(m))
	for key := range m {
		keys = append(keys, key)
	}
	sort.Strings(keys)
	return keys
}

func mergeFields(base, extra []Field) []Field {
	byName := map[string]TypeSpec{}
	for _, field := range base {
		byName[field.Name] = field.Spec
	}
	for _, field := range extra {
		byName[field.Name] = field.Spec
	}
	merged := make([]Field, 0, len(byName))
	for _, name := range sortedKeys(byName) {
		merged = append(merged, Field{Name: name, Spec: byName[name]})
	}
	return merged
}

func mergeNames(base, extra []string) []string {
	set := map[string]bool{}
	for _, name := range append(append([]string{}, base...), extra...) {
		set[name] = true
	}
	return sortedKeys(set)
}

package effective

import (
	"fmt"
	"sort"
	"strings"

	"github.com/hostingpal/whm-api-client/tools/api-map/internal/overlay"
)

type segment struct {
	name     string
	suffixes []string
}

// parsePath splits "acct[].uid" into fields with list ("[]") and map ("{}") steps.
func parsePath(path string) ([]segment, error) {
	if path == "" {
		return nil, nil
	}
	var segments []segment
	for i, part := range strings.Split(path, ".") {
		seg := segment{}
		for strings.HasSuffix(part, "[]") || strings.HasSuffix(part, "{}") {
			seg.suffixes = append([]string{part[len(part)-2:]}, seg.suffixes...)
			part = part[:len(part)-2]
		}
		seg.name = part
		if seg.name == "" && i > 0 {
			return nil, fmt.Errorf("invalid response path %q", path)
		}
		segments = append(segments, seg)
	}
	return segments, nil
}

func fieldIndex(spec *TypeSpec, name string) int {
	for i := range spec.Fields {
		if spec.Fields[i].Name == name {
			return i
		}
	}
	return -1
}

// applyCorrection changes the spec at path; "add" declares an undocumented field.
func applyCorrection(root *TypeSpec, path string, c overlay.Correction) error {
	segments, err := parsePath(path)
	if err != nil {
		return err
	}
	current := root
	var parent *TypeSpec
	field := ""
	for i, seg := range segments {
		if seg.name != "" {
			if current.Type != "object" {
				return fmt.Errorf("path %q: %q is not an object field", path, seg.name)
			}
			index := fieldIndex(current, seg.name)
			if index < 0 {
				if i != len(segments)-1 || c.Add == nil {
					return fmt.Errorf("path %q: field %q is not documented", path, seg.name)
				}
				current.Fields = append(current.Fields, Field{Name: seg.name, Spec: fromOverlay(*c.Add)})
				sort.Slice(current.Fields, func(a, b int) bool { return current.Fields[a].Name < current.Fields[b].Name })
				index = fieldIndex(current, seg.name)
			}
			parent, field = current, seg.name
			current = &current.Fields[index].Spec
		}
		for _, suffix := range seg.suffixes {
			if suffix == "[]" {
				if current.Items == nil {
					return fmt.Errorf("path %q: not a list", path)
				}
				current = current.Items
			} else {
				if current.Values == nil {
					return fmt.Errorf("path %q: not a map", path)
				}
				current = current.Values
			}
			parent, field = nil, ""
		}
	}
	if c.Type != "" {
		*current = TypeSpec{Type: c.Type, Nullable: current.Nullable}
	}
	if len(c.Accept) > 0 {
		current.Accept = append([]string(nil), c.Accept...)
	}
	if c.Nullable != nil {
		current.Nullable = *c.Nullable
	}
	if c.Preserve {
		current.Preserve = true
	}
	if c.Required != nil {
		if parent == nil {
			return fmt.Errorf("path %q: required applies to object fields", path)
		}
		parent.Required = setName(parent.Required, field, *c.Required)
	}
	return nil
}

func setName(names []string, name string, present bool) []string {
	set := map[string]bool{}
	for _, existing := range names {
		set[existing] = true
	}
	if present {
		set[name] = true
	} else {
		delete(set, name)
	}
	return sortedKeys(set)
}

func fromOverlay(s overlay.Spec) TypeSpec {
	spec := TypeSpec{Type: s.Type, Nullable: s.Nullable, Accept: s.Accept, Preserve: s.Preserve, Required: s.Required}
	if s.Items != nil {
		items := fromOverlay(*s.Items)
		spec.Items = &items
	}
	if s.Values != nil {
		values := fromOverlay(*s.Values)
		spec.Values = &values
	}
	for _, name := range sortedKeys(s.Fields) {
		spec.Fields = append(spec.Fields, Field{Name: name, Spec: fromOverlay(s.Fields[name])})
	}
	for _, option := range s.AnyOf {
		spec.AnyOf = append(spec.AnyOf, fromOverlay(option))
	}
	return spec
}

var (
	markdownLink  = regexp.MustCompile(`\[([^\]]+)\]\([^)]*\)`)
	whitespace    = regexp.MustCompile(`\s+`)
	blankLine     = regexp.MustCompile(`\n\s*\n`)
	reservedNames = map[string]bool{"call": true, "responseMeta": true, "username": true, "isBridged": true}
	secretNames   = map[string]bool{"pass": true, "passwd": true, "newpass": true, "token": true, "secret": true, "api_token": true, "private_key": true}
)

type overlayEntry struct {
	file *overlay.File
	op   overlay.Operation
}

type builder struct {
	schemas  schemas
	set      overlay.Set
	entries  map[string]overlayEntry
	files    map[string]*overlay.File
	problems map[string]bool
	result   Result
}

// Build applies the overlay to the map and returns the effective contract.
func Build(m model.Map, set overlay.Set) (Result, error) {
	s, err := newSchemas(m)
	if err != nil {
		return Result{}, err
	}
	b := &builder{schemas: s, set: set, entries: map[string]overlayEntry{}, files: map[string]*overlay.File{}, problems: map[string]bool{}}
	for i := range set.Files {
		file := &set.Files[i]
		b.files[file.Family+"|"+file.Group] = file
		for id, op := range file.Operations {
			b.entries[id] = overlayEntry{file: file, op: op}
		}
	}
	known := map[string]bool{}
	groups := map[string]*Group{}
	operations := append([]model.Operation(nil), m.Operations...)
	sort.Slice(operations, func(i, j int) bool { return operations[i].ID < operations[j].ID })
	for _, op := range operations {
		known[op.ID] = true
		entry, listed := b.entries[op.ID]
		if listed && entry.op.Exclude != nil {
			b.result.Excluded = append(b.result.Excluded, Exclusion{ID: op.ID, Reason: entry.op.Exclude.Reason})
			continue
		}
		if set.Config.Scope == "listed" && !listed {
			continue
		}
		if len(op.Variants) != 1 {
			b.problem(op.ID + ": operations with several variants need an overlay decision")
			continue
		}
		operation, groupName, ok := b.operation(op, op.Variants[0], entry.op)
		if !ok {
			continue
		}
		if groupName == "" {
			b.problem(op.ID + ": has no group")
			continue
		}
		if listed && entry.file.Group != groupName {
			b.problem(fmt.Sprintf("%s: belongs to group %q, not %q", op.ID, groupName, entry.file.Group))
		}
		key := op.Family + "|" + groupName
		if groups[key] == nil {
			groups[key] = b.group(op.Family, groupName, op.Variants[0])
		}
		groups[key].Operations = append(groups[key].Operations, operation)
	}
	for id := range b.entries {
		if !known[id] {
			b.problem(id + ": not in the API map")
		}
	}
	b.finish(groups)
	return b.result, nil
}

func (b *builder) problem(message string) { b.problems[message] = true }

func (b *builder) operation(op model.Operation, v model.Variant, ov overlay.Operation) (Operation, string, bool) {
	returns, node, err := b.schemas.payload(op, v)
	if err != nil {
		b.problem(err.Error())
		return Operation{}, "", false
	}
	result := Operation{
		ID:          op.ID,
		VariantID:   v.ID,
		Family:      op.Family,
		Function:    op.Function,
		Outcome:     firstNonEmpty(ov.Outcome, "flag"),
		Summary:     sentence(text(node["summary"])),
		Description: firstParagraph(text(node["description"])),
		Subcategory: subcategory(op.Family, node),
		SeeURL:      seeURL(op),
		Notes:       ov.Notes,
		Unwrap:      ov.Unwrap,
		Constant:    Constant(op.Function),
	}
	if strings.TrimSuffix(result.Description, ".") == strings.TrimSuffix(result.Summary, ".") {
		result.Description = ""
	}
	if op.Module != nil {
		result.Module = *op.Module
	}
	result.PHPName = b.methodName(op, ov)
	result.Alias = Pascal(result.PHPName) + "Result"
	result.Params = b.params(op, v, ov)
	result.Method = b.method(op, v, ov, result.Params)
	if ov.Void {
		returns = nil
	}
	if returns != nil {
		for _, path := range sortedKeys(ov.Response) {
			if err := applyCorrection(returns, path, ov.Response[path]); err != nil {
				b.problem(op.ID + ": " + err.Error())
			}
		}
	} else if len(ov.Response) > 0 {
		b.problem(op.ID + ": response corrections need a documented payload")
	}
	if ov.Unwrap != "" && (returns == nil || returns.Type != "object" || fieldIndex(returns, ov.Unwrap) < 0) {
		b.problem(op.ID + ": unwrap field " + ov.Unwrap + " is not a documented object field")
	}
	result.Returns = returns
	return result, b.groupOf(op, v, node), true
}

func (b *builder) methodName(op model.Operation, ov overlay.Operation) string {
	if ov.Name != "" {
		return ov.Name
	}
	trimmed := strings.TrimLeft(op.Function, "_")
	if !strings.Contains(trimmed, "_") || trimmed != op.Function || strings.Contains(op.Function, "/") {
		b.problem(op.ID + ": needs an explicit overlay name")
	}
	return Camel(op.Function)
}

func (b *builder) params(op model.Operation, v model.Variant, ov overlay.Operation) []Param {
	var required, optional []Param
	used := map[string]bool{}
	documented := map[string]bool{}
	for _, p := range v.Parameters {
		if p.In != "query" {
			continue
		}
		documented[p.Name] = true
		if o, ok := ov.Params[p.Name]; ok && o.Omit {
			continue
		}
		if strings.ContainsAny(p.Name, "*") {
			b.problem(op.ID + ": parameter " + p.Name + " is a name pattern; omit it and use call()")
			continue
		}
		decl := p.Definition
		spec := b.schemas.specFor(p.Locator.SourceID, decl["schema"], 0, nil)
		param := Param{
			Wire:        p.Name,
			PHP:         Camel(p.Name),
			Required:    decl["required"] == true,
			Description: firstSentence(text(decl["description"])),
			Sensitive:   sensitiveName(p.Name),
		}
		param.PHPType, param.DocType, param.Encoding = paramTypes(spec, b.schemas.enumDoc(p.Locator.SourceID, decl["schema"]))
		if o, ok := ov.Params[p.Name]; ok {
			if o.PHP != "" {
				param.PHP = o.PHP
			}
			if o.Encoding != "" {
				param.PHPType, param.DocType, param.Encoding = encodingTypes(o.Encoding, param)
			}
			if o.Sensitive != nil {
				param.Sensitive = *o.Sensitive
			}
		}
		if !IsMethodName(param.PHP) {
			b.problem(op.ID + ": parameter " + p.Name + " needs an overlay php name")
		}
		if used[param.PHP] {
			b.problem(op.ID + ": duplicate argument name " + param.PHP)
		}
		used[param.PHP] = true
		if param.Required {
			required = append(required, param)
		} else {
			optional = append(optional, param)
		}
	}
	for _, wire := range sortedKeys(ov.Params) {
		if !documented[wire] {
			b.problem(op.ID + ": overlay parameter " + wire + " is not documented")
		}
	}
	for _, wire := range ov.Order {
		if !documented[wire] {
			b.problem(op.ID + ": order lists undocumented parameter " + wire)
		}
	}
	return append(orderParams(required, ov.Order), orderParams(optional, ov.Order)...)
}

// orderParams moves parameters named in order (by wire name) to the front, in
// that order, keeping the documented order for the rest. Required parameters
// always precede optional ones.
func orderParams(params []Param, order []string) []Param {
	rank := map[string]int{}
	for i, wire := range order {
		rank[wire] = i
	}
	sort.SliceStable(params, func(i, j int) bool {
		ri, iListed := rank[params[i].Wire]
		rj, jListed := rank[params[j].Wire]
		switch {
		case iListed && jListed:
			return ri < rj
		case iListed != jListed:
			return iListed
		}
		return false
	})
	return params
}

func (b *builder) method(op model.Operation, v model.Variant, ov overlay.Operation, params []Param) string {
	sensitive := false
	for _, p := range params {
		sensitive = sensitive || p.Sensitive
	}
	if ov.Method != "" {
		if ov.Method == "GET" && sensitive {
			b.problem(op.ID + ": secret-bearing parameters require POST")
		}
		return ov.Method
	}
	if v.Risk.Classification == "read-only" && !sensitive {
		return "GET"
	}
	return "POST"
}

func (b *builder) groupOf(op model.Operation, v model.Variant, node map[string]any) string {
	if op.Family == "uapi" {
		if op.Module == nil {
			return ""
		}
		return *op.Module
	}
	groups := tagGroups(b.schemas.m.Documents[v.OperationLocator.SourceID])
	tags, _ := node["tags"].([]any)
	for _, tag := range tags {
		if name, ok := groups[fmt.Sprint(tag)]; ok {
			return name
		}
	}
	return ""
}

func (b *builder) group(family, name string, v model.Variant) *Group {
	group := &Group{Family: family, Name: name}
	file := b.files[family+"|"+name]
	if family == "uapi" {
		group.Accessor = Camel(name)
		group.Class = Pascal(name)
		group.Description = tagDescription(b.schemas.m.Documents[v.OperationLocator.SourceID], name)
		if group.Description == "" {
			group.Description = "UAPI " + name + " module functions."
		}
	} else {
		group.Accessor = Camel(name)
		if file == nil || file.Accessor == "" {
			b.problem(fmt.Sprintf("WHM group %q needs an overlay file with an accessor", name))
		}
		group.Description = "WHM API 1 functions in the documented " + name + " group."
	}
	if file != nil {
		if file.Accessor != "" {
			group.Accessor = file.Accessor
		}
		if file.Description != "" {
			group.Description = file.Description
		}
	}
	group.Class = Pascal(group.Accessor)
	if file != nil && file.Class != "" {
		group.Class = file.Class
	}
	if family == "uapi" && (file == nil || file.Class == "") {
		group.Class = Pascal(name)
	}
	return group
}

func (b *builder) finish(groups map[string]*Group) {
	accessors := map[string]string{}
	for _, key := range sortedKeys(groups) {
		group := groups[key]
		sort.Slice(group.Operations, func(i, j int) bool { return group.Operations[i].PHPName < group.Operations[j].PHPName })
		if reservedNames[group.Accessor] || !IsMethodName(group.Accessor) {
			b.problem(fmt.Sprintf("group %q: accessor %q is reserved or invalid", group.Name, group.Accessor))
		}
		if !IsClassName(group.Class) {
			b.problem(fmt.Sprintf("group %q: class %q is invalid", group.Name, group.Class))
		}
		accessorKey := group.Family + "|" + group.Accessor
		if other, taken := accessors[accessorKey]; taken {
			b.problem(fmt.Sprintf("groups %q and %q share accessor %q", other, group.Name, group.Accessor))
		}
		accessors[accessorKey] = group.Name
		names := map[string]bool{}
		constants := map[string]bool{}
		for _, op := range group.Operations {
			if names[op.PHPName] {
				b.problem(fmt.Sprintf("group %q: duplicate method %s", group.Name, op.PHPName))
			}
			if constants[op.Constant] {
				b.problem(fmt.Sprintf("group %q: duplicate spec constant %s", group.Name, op.Constant))
			}
			if !IsMethodName(op.PHPName) {
				b.problem(op.ID + ": method name " + op.PHPName + " is invalid")
			}
			names[op.PHPName] = true
			constants[op.Constant] = true
		}
		b.result.Groups = append(b.result.Groups, *group)
	}
	sort.SliceStable(b.result.Groups, func(i, j int) bool {
		if b.result.Groups[i].Family != b.result.Groups[j].Family {
			return b.result.Groups[i].Family < b.result.Groups[j].Family
		}
		return b.result.Groups[i].Class < b.result.Groups[j].Class
	})
	sort.Slice(b.result.Excluded, func(i, j int) bool { return b.result.Excluded[i].ID < b.result.Excluded[j].ID })
	b.result.Problems = sortedKeys(b.problems)
}

func paramTypes(spec TypeSpec, enumDoc string) (string, string, string) {
	switch spec.Type {
	case "flag", "bool":
		return "bool", "bool", "bool"
	case "int":
		return "int", firstNonEmpty(enumDoc, "int"), "scalar"
	case "number":
		return "int|float", "int|float", "scalar"
	case "string":
		return "string", firstNonEmpty(enumDoc, "string"), "scalar"
	case "list":
		return "string|array", "string|list<string>", "repeat"
	}
	return "string|int", "string|int", "scalar"
}

func encodingTypes(encoding string, current Param) (string, string, string) {
	switch encoding {
	case "numbered":
		return "string|array", "string|list<string>", "numbered"
	case "repeat":
		return "string|array", "string|list<string>", "repeat"
	case "bool":
		return "bool", "bool", "bool"
	}
	if current.Encoding == "scalar" {
		return current.PHPType, current.DocType, "scalar"
	}
	return "string|int", "string|int", "scalar"
}

func sensitiveName(name string) bool {
	lower := strings.ToLower(name)
	return strings.Contains(lower, "password") || secretNames[lower]
}

func tagGroups(doc model.Object) map[string]string {
	result := map[string]string{}
	groups, _ := doc["x-tagGroups"].([]any)
	for _, g := range groups {
		obj, _ := asObject(g)
		name, _ := obj["name"].(string)
		tags, _ := obj["tags"].([]any)
		for _, tag := range tags {
			result[fmt.Sprint(tag)] = name
		}
	}
	return result
}

func tagDescription(doc model.Object, name string) string {
	tags, _ := doc["tags"].([]any)
	for _, tag := range tags {
		obj, _ := asObject(tag)
		if obj["name"] == name {
			return firstParagraph(text(obj["description"]))
		}
	}
	return ""
}

func subcategory(family string, node map[string]any) string {
	if family == "uapi" {
		return ""
	}
	tags, _ := node["tags"].([]any)
	if len(tags) == 0 {
		return ""
	}
	return fmt.Sprint(tags[len(tags)-1])
}

func seeURL(op model.Operation) string {
	site := "whm"
	if op.Family == "uapi" {
		site = "cpanel"
	}
	return "https://api.docs.cpanel.net/openapi/" + site + "/operation/" + op.Function
}

func text(v any) string {
	s, _ := v.(string)
	return s
}

func clean(s string) string {
	s = markdownLink.ReplaceAllString(s, "$1")
	s = strings.NewReplacer("**", "", "__", "").Replace(s)
	return strings.TrimSpace(whitespace.ReplaceAllString(s, " "))
}

func firstParagraph(s string) string {
	for _, paragraph := range blankLine.Split(s, -1) {
		if cleaned := clean(paragraph); cleaned != "" {
			return cleaned
		}
	}
	return ""
}

func firstSentence(s string) string {
	paragraph := firstParagraph(s)
	if i := strings.Index(paragraph, ". "); i >= 0 {
		return paragraph[:i+1]
	}
	return paragraph
}

func sentence(s string) string {
	cleaned := clean(s)
	if cleaned != "" && !strings.HasSuffix(cleaned, ".") {
		cleaned += "."
	}
	return cleaned
}

func firstNonEmpty(values ...string) string {
	for _, value := range values {
		if value != "" {
			return value
		}
	}
	return ""
}

// Package phpgen renders the effective contract as PHP group classes, spec
// classes, handle accessor traits and a coverage summary.
package phpgen

import (
	"regexp"
	"strings"

	"github.com/hostingpal/whm-api-client/tools/api-map/internal/effective"
)

const lineWidth = 120

var shapeKey = regexp.MustCompile(`^[A-Za-z_][A-Za-z0-9_]*$`)

func phpString(s string) string {
	return "'" + strings.ReplaceAll(strings.ReplaceAll(s, `\`, `\\`), "'", `\'`) + "'"
}

func escapeDoc(s string) string { return strings.ReplaceAll(s, "*/", `*\/`) }

func wrap(text string, width int) []string {
	var lines []string
	current := ""
	for _, word := range strings.Fields(text) {
		switch {
		case current == "":
			current = word
		case len(current)+1+len(word) > width:
			lines = append(lines, current)
			current = word
		default:
			current += " " + word
		}
	}
	if current != "" {
		lines = append(lines, current)
	}
	return lines
}

// shape renders a PHPStan type; objects with fields span lines indented by indent.
func shape(spec effective.TypeSpec, indent string) string {
	base := baseShape(spec, indent)
	if spec.Nullable && base != "mixed" {
		base += "|null"
	}
	return base
}

func baseShape(spec effective.TypeSpec, indent string) string {
	switch spec.Type {
	case "string":
		return "string"
	case "int":
		return "int"
	case "number":
		if spec.Preserve {
			return "int|float|numeric-string"
		}
		return "int|float"
	case "bool":
		return "bool"
	case "flag":
		return "0|1"
	case "list":
		return "list<" + shape(*spec.Items, indent) + ">"
	case "map":
		return "array<array-key, " + shape(*spec.Values, indent) + ">"
	case "union":
		var parts []string
		seen := map[string]bool{}
		for _, option := range spec.AnyOf {
			part := shape(option, indent)
			if part == "mixed" {
				return "mixed"
			}
			if !seen[part] {
				seen[part] = true
				parts = append(parts, part)
			}
		}
		return strings.Join(parts, "|")
	case "object":
		if len(spec.Fields) == 0 {
			return "array<string, mixed>"
		}
		inner := indent + "    "
		lines := []string{"array{"}
		required := map[string]bool{}
		for _, name := range spec.Required {
			required[name] = true
		}
		for _, field := range spec.Fields {
			key := field.Name
			if !shapeKey.MatchString(key) {
				key = phpString(key)
			}
			optional := "?"
			if required[field.Name] {
				optional = ""
			}
			lines = append(lines, inner+key+optional+": "+shape(field.Spec, inner)+",")
		}
		lines = append(lines, indent+"}")
		return strings.Join(lines, "\n")
	}
	return "mixed"
}

// nativeType renders the PHP return or property type for a spec.
func nativeType(spec effective.TypeSpec) string {
	var types []string
	switch spec.Type {
	case "string":
		types = []string{"string"}
	case "int", "flag":
		types = []string{"int"}
	case "number":
		types = []string{"int", "float"}
		if spec.Preserve {
			types = append(types, "string")
		}
	case "bool":
		types = []string{"bool"}
	case "list", "map", "object":
		types = []string{"array"}
	case "union":
		seen := map[string]bool{}
		for _, option := range spec.AnyOf {
			native := nativeType(effective.TypeSpec{Type: option.Type, Preserve: option.Preserve, AnyOf: option.AnyOf})
			if native == "mixed" {
				return "mixed"
			}
			for _, part := range strings.Split(native, "|") {
				if !seen[part] {
					seen[part] = true
					types = append(types, part)
				}
			}
		}
	default:
		return "mixed"
	}
	if spec.Nullable || (spec.Type == "union" && unionNullable(spec)) {
		if len(types) == 1 {
			return "?" + types[0]
		}
		types = append(types, "null")
	}
	return strings.Join(types, "|")
}

func unionNullable(spec effective.TypeSpec) bool {
	for _, option := range spec.AnyOf {
		if option.Nullable {
			return true
		}
	}
	return false
}

// isArrayLike reports whether the spec's PHPStan type is an array shape worth an alias.
func isArrayLike(spec effective.TypeSpec) bool {
	switch spec.Type {
	case "list", "map", "object":
		return true
	case "union":
		for _, option := range spec.AnyOf {
			if isArrayLike(option) {
				return true
			}
		}
	}
	return false
}

func listLiteral(values []string, indent string) string {
	quoted := make([]string, len(values))
	for i, value := range values {
		quoted[i] = phpString(value)
	}
	inline := "[" + strings.Join(quoted, ", ") + "]"
	if len(indent)+len(inline) <= 100 {
		return inline
	}
	lines := []string{"["}
	for _, value := range quoted {
		lines = append(lines, indent+"    "+value+",")
	}
	lines = append(lines, indent+"]")
	return strings.Join(lines, "\n")
}

// specLiteral renders a type spec as a PHP array literal. Scalars stay inline;
// containers break across lines with trailing commas (PHPCS TrailingArrayComma).
func specLiteral(spec effective.TypeSpec, indent string) string {
	type pair struct{ key, value string }
	inner := indent + "    "
	pairs := []pair{{"type", phpString(spec.Type)}}
	if spec.Nullable {
		pairs = append(pairs, pair{"nullable", "true"})
	}
	if len(spec.Accept) > 0 {
		pairs = append(pairs, pair{"accept", listLiteral(spec.Accept, inner)})
	}
	if spec.Preserve {
		pairs = append(pairs, pair{"preserve", "true"})
	}
	if spec.Items != nil {
		pairs = append(pairs, pair{"items", specLiteral(*spec.Items, inner)})
	}
	if spec.Values != nil {
		pairs = append(pairs, pair{"values", specLiteral(*spec.Values, inner)})
	}
	if spec.Type == "object" {
		fields := "[]"
		if len(spec.Fields) > 0 {
			lines := []string{"["}
			for _, field := range spec.Fields {
				lines = append(lines, inner+"    "+phpString(field.Name)+" => "+specLiteral(field.Spec, inner+"    ")+",")
			}
			lines = append(lines, inner+"]")
			fields = strings.Join(lines, "\n")
		}
		pairs = append(pairs, pair{"fields", fields})
		if len(spec.Required) > 0 {
			pairs = append(pairs, pair{"required", listLiteral(spec.Required, inner)})
		}
	}
	if len(spec.AnyOf) > 0 {
		lines := []string{"["}
		for _, option := range spec.AnyOf {
			lines = append(lines, inner+"    "+specLiteral(option, inner+"    ")+",")
		}
		lines = append(lines, inner+"]")
		pairs = append(pairs, pair{"anyOf", strings.Join(lines, "\n")})
	}
	parts := make([]string, len(pairs))
	for i, p := range pairs {
		parts[i] = phpString(p.key) + " => " + p.value
	}
	inline := "[" + strings.Join(parts, ", ") + "]"
	if !strings.Contains(inline, "\n") && spec.Type != "object" && len(spec.AnyOf) == 0 && len(indent)+len(inline) <= 100 {
		return inline
	}
	lines := []string{"["}
	for _, part := range parts {
		lines = append(lines, inner+part+",")
	}
	lines = append(lines, indent+"]")
	return strings.Join(lines, "\n")
}

package phpgen

import (
	"fmt"
	"sort"
	"strings"

	"github.com/hostingpal/whm-api-client/tools/api-map/internal/effective"
)

// Marker identifies generated files; files without it are never touched.
const Marker = "Generated by tools/api-map from the pinned API map and docs/api/overlay; do not edit."

const rootNamespace = `HostingPal\WhmApiClient`

type writer struct{ b strings.Builder }

func (w *writer) line(s string) {
	w.b.WriteString(s)
	w.b.WriteByte('\n')
}

func (w *writer) doc(indent, text string) {
	for _, l := range wrap(escapeDoc(text), lineWidth-len(indent)-3) {
		w.line(indent + " * " + l)
	}
}

// docTag writes a tag line whose type may span lines (multi-line shapes).
func (w *writer) docTag(indent, text string) {
	for _, l := range strings.Split(text, "\n") {
		w.line(strings.TrimRight(indent+" * "+l, " "))
	}
}

// Render returns generated file contents keyed by repository-relative path.
func Render(result effective.Result) map[string][]byte {
	files := map[string][]byte{}
	byFamily := map[string][]effective.Group{}
	for _, group := range result.Groups {
		dir := familyDir(group.Family)
		files["src/Api/"+dir+"/"+group.Class+".php"] = []byte(groupClass(group))
		files["src/Api/"+dir+"/Spec/"+group.Class+"Spec.php"] = []byte(specClass(group))
		byFamily[group.Family] = append(byFamily[group.Family], group)
	}
	for family, groups := range byFamily {
		dir := familyDir(family)
		files["src/Api/"+dir+"/"+dir+"Groups.php"] = []byte(groupsTrait(family, groups))
	}
	files["docs/api/coverage.md"] = []byte(coverage(result))
	return files
}

func familyDir(family string) string {
	if family == "uapi" {
		return "Uapi"
	}
	return "Whm"
}

func header(w *writer, namespace string) {
	w.line("<?php")
	w.line("")
	w.line("declare(strict_types=1);")
	w.line("")
	w.line("namespace " + namespace + ";")
	w.line("")
}

func lifecycle(family string) string {
	if family == "uapi" {
		return "Each method executes one request immediately for this handle's cPanel account, through direct cPanel " +
			"access or WHM according to the configured credentials, with a single attempt and no retries. The handle " +
			"clears responseMeta() before every attempt and records the envelope snapshot before API or payload errors."
	}
	return "Each method executes one WHM API 1 request immediately with a single attempt and no retries. The handle " +
		"clears responseMeta() before every attempt and records the envelope snapshot before API or payload errors."
}

func resultSpec(op effective.Operation) *effective.TypeSpec {
	if op.Returns == nil {
		return nil
	}
	if op.Unwrap == "" {
		return op.Returns
	}
	for _, field := range op.Returns.Fields {
		if field.Name == op.Unwrap {
			spec := field.Spec
			return &spec
		}
	}
	return &effective.TypeSpec{Type: "mixed"}
}

func docReturn(op effective.Operation, spec effective.TypeSpec) string {
	if isArrayLike(spec) {
		return op.Alias
	}
	return shape(spec, "")
}

func groupClass(g effective.Group) string {
	namespace := rootNamespace + `\Api\` + familyDir(g.Family)
	w := &writer{}
	header(w, namespace)
	uses := []string{"Closure", namespace + `\Spec\` + g.Class + "Spec", rootNamespace + `\Exception\ApiException`}
	for _, op := range g.Operations {
		for _, p := range op.Params {
			if p.Encoding == "repeat" || p.Encoding == "numbered" {
				uses = append(uses, "InvalidArgumentException")
			}
			if p.Sensitive {
				uses = append(uses, "SensitiveParameter")
			}
		}
	}
	for _, use := range uniqueSorted(uses) {
		w.line("use " + use + ";")
	}
	w.line("")
	w.line("/**")
	w.doc("", g.Description)
	w.line(" *")
	w.doc("", lifecycle(g.Family))
	w.line(" *")
	w.doc("", Marker)
	aliases := false
	for _, op := range g.Operations {
		spec := resultSpec(op)
		if spec == nil || !isArrayLike(*spec) {
			continue
		}
		if !aliases {
			w.line(" *")
			aliases = true
		}
		w.docTag("", "@phpstan-type "+op.Alias+" "+shape(*spec, ""))
	}
	w.line(" */")
	w.line("final readonly class " + g.Class)
	w.line("{")
	w.line("    /**")
	w.line("     * Bind the group to its handle's operation runner.")
	w.line("     *")
	w.line("     * @param Closure(array<mixed>, array<string, mixed>): mixed $run")
	w.line("     * @internal Obtain this group through the handle's accessor.")
	w.line("     */")
	w.line("    public function __construct(private Closure $run)")
	w.line("    {")
	w.line("    }")
	for _, op := range g.Operations {
		w.line("")
		method(w, g, op)
	}
	w.line("}")
	return w.b.String()
}

func paramDocType(p effective.Param) string {
	if p.Required {
		return p.DocType
	}
	return p.DocType + "|null"
}

func paramNative(p effective.Param) string {
	if p.Required {
		return p.PHPType
	}
	if strings.Contains(p.PHPType, "|") {
		return p.PHPType + "|null"
	}
	return "?" + p.PHPType
}

func method(w *writer, g effective.Group, op effective.Operation) {
	const indent = "    "
	ret := resultSpec(op)
	w.line(indent + "/**")
	w.doc(indent, op.Summary)
	if op.Description != "" {
		w.line(indent + " *")
		w.doc(indent, op.Description)
	}
	for _, note := range op.Notes {
		w.line(indent + " *")
		w.doc(indent, "Observed: "+note)
	}
	w.line(indent + " *")
	identity := "API-map identity: " + op.VariantID + " (wire name " + op.Function
	if op.Subcategory != "" {
		identity += "; " + op.Subcategory
	}
	w.doc(indent, identity+").")
	w.line(indent + " *")
	multi := false
	for _, p := range op.Params {
		description := p.Description
		if !p.Required {
			description = strings.TrimSpace(description + " Null omits it.")
		}
		w.doc(indent, "@param "+paramDocType(p)+" $"+p.PHP+" "+description)
		multi = multi || p.Encoding == "repeat" || p.Encoding == "numbered"
	}
	if ret != nil {
		w.docTag(indent, "@return "+docReturn(op, *ret))
	}
	w.line(indent + " * @throws ApiException If transport, HTTP, the outcome, or the payload fails.")
	if multi {
		w.line(indent + " * @throws InvalidArgumentException If a list argument is empty or contains non-strings.")
	}
	w.line(indent + " * @see " + op.SeeURL)
	w.line(indent + " */")
	signature(w, op, ret)
	body(w, g, op, ret)
	w.line(indent + "}")
}

func signature(w *writer, op effective.Operation, ret *effective.TypeSpec) {
	native := "void"
	if ret != nil {
		native = nativeType(*ret)
	}
	parts := make([]string, len(op.Params))
	sensitive := false
	for i, p := range op.Params {
		parts[i] = paramNative(p) + " $" + p.PHP
		if !p.Required {
			parts[i] += " = null"
		}
		sensitive = sensitive || p.Sensitive
	}
	single := "    public function " + op.PHPName + "(" + strings.Join(parts, ", ") + "): " + native
	if !sensitive && len(single) <= lineWidth {
		w.line(single)
		w.line("    {")
		return
	}
	w.line("    public function " + op.PHPName + "(")
	for i, p := range op.Params {
		if p.Sensitive {
			w.line("        #[SensitiveParameter]")
		}
		w.line("        " + parts[i] + ",")
	}
	w.line("    ): " + native + " {")
}

func body(w *writer, g effective.Group, op effective.Operation, ret *effective.TypeSpec) {
	constant := g.Class + "Spec::" + op.Constant
	arguments := make([]string, len(op.Params))
	for i, p := range op.Params {
		arguments[i] = phpString(p.PHP) + " => $" + p.PHP
	}
	call := "($this->run)(" + constant + ", [" + strings.Join(arguments, ", ") + "])"
	prefix := "        "
	if ret != nil {
		prefix = "        $result = "
		w.line("        /** @var " + docReturn(op, *ret) + " $result Validated against " + constant + ". */")
	}
	if len(prefix+call)+1 <= lineWidth {
		w.line(prefix + call + ";")
	} else {
		w.line(prefix + "($this->run)(" + constant + ", [")
		for _, argument := range arguments {
			w.line("            " + argument + ",")
		}
		w.line("        ]);")
	}
	if ret != nil {
		w.line("")
		w.line("        return $result;")
	}
}

	w.line("/**")
	w.doc("", "Operation specs for the "+g.Class+" group, consumed by Api\\Engine\\OperationRunner.")
	w.line(" *")
	w.doc("", Marker)
	w.line(" *")
	w.line(" * @internal")
	w.line(" */")
	w.line("final class " + g.Class + "Spec")

		if i > 0 {
			w.line("")
		}

		if op.Module != "" {
			w.line("        'module' => " + phpString(op.Module) + ",")

	w.doc("", Marker)
	w.line(" *")
	w.line(" * @internal")
	w.line(" */")
	w.line("trait " + dir + "Groups")
	w.line("{")
	for _, g := range groups {
		w.line("    private ?" + g.Class + " $" + g.Accessor + "Group = null;")
		w.line("")
	}

		w.doc("    ", g.Description)

		w.line("    }")
	}
	w.line("}")
	return w.b.String()
}

func coverage(result effective.Result) string {
	w := &writer{}
	w.line("# Generated API coverage")
	w.line("")
	w.line(Marker)
	w.line("")
	counts := map[string][3]int{}
	for _, g := range result.Groups {
		c := counts[g.Family]
		c[0]++
		c[1] += len(g.Operations)
		counts[g.Family] = c
	}
	for _, e := range result.Excluded {
		family := strings.SplitN(e.ID, ":", 2)[0]
		c := counts[family]
		c[2]++
		counts[family] = c
	}
	label := map[string]string{"uapi": "UAPI", "whm1": "WHM API 1"}
	w.line("| Family | Groups | Generated operations | Excluded |")
	w.line("| --- | ---: | ---: | ---: |")
	for _, family := range []string{"uapi", "whm1"} {
		c := counts[family]
		w.line(fmt.Sprintf("| %s | %d | %d | %d |", label[family], c[0], c[1], c[2]))
	}
	w.line("")
	w.line("## Groups")
	w.line("")
	w.line("| Family | Group | Accessor | Operations |")
	w.line("| --- | --- | --- | ---: |")
	for _, g := range result.Groups {
		handle := map[string]string{"uapi": "uapi()", "whm1": "whm()"}[g.Family]
		w.line(fmt.Sprintf("| %s | %s | `%s->%s()` | %d |", label[g.Family], g.Name, handle, g.Accessor, len(g.Operations)))
	}
	if len(result.Excluded) > 0 {
		w.line("")
		w.line("## Excluded operations")
		w.line("")
		w.line("| Operation | Reason |")
		w.line("| --- | --- |")
		for _, e := range result.Excluded {
			w.line(fmt.Sprintf("| `%s` | %s |", e.ID, strings.ReplaceAll(e.Reason, "|", `\|`)))
		}
	}
	return w.b.String()
}

func uniqueSorted(values []string) []string {
	set := map[string]bool{}
	for _, value := range values {
		set[value] = true
	}
	result := make([]string, 0, len(set))
	for value := range set {
		result = append(result, value)
	}
	sort.Strings(result)
	return result
}

import (

func overlayValidate(_ context.Context, args []string, stdout, stderr io.Writer) int {
	f := flags("overlay validate")
	mapPath := f.String("map", "", "")
	overlayDir := f.String("overlay", "", "")
	if err := f.Parse(args); err != nil || *mapPath == "" || *overlayDir == "" || f.NArg() != 0 {
		return usage(stderr)
	}
	result, ok := effectiveContract(*mapPath, *overlayDir, stderr)
	if !ok {
		return 1
	}
	operations := 0
	for _, group := range result.Groups {
		operations += len(group.Operations)
	}
	fmt.Fprintf(stdout, "overlay valid: %d groups, %d operations, %d excluded\n", len(result.Groups), operations, len(result.Excluded))
	return 0
}

func generatePHP(_ context.Context, args []string, stdout, stderr io.Writer) int {
	f := flags("generate php")
	mapPath := f.String("map", "", "")
	overlayDir := f.String("overlay", "", "")
	root := f.String("root", "", "")
	check := f.Bool("check", false, "")
	if err := f.Parse(args); err != nil || *mapPath == "" || *overlayDir == "" || *root == "" || f.NArg() != 0 {
		return usage(stderr)
	}
	result, ok := effectiveContract(*mapPath, *overlayDir, stderr)
	if !ok {
		return 1
	}
	files := phpgen.Render(result)
	stale, err := staleGenerated(*root, files)
	if err != nil {
		fmt.Fprintln(stderr, "api-map:", err)
		return 1
	}
	paths := make([]string, 0, len(files))
	for path := range files {
		paths = append(paths, path)
	}
	sort.Strings(paths)
	if *check {
		var outdated []string
		for _, path := range paths {
			current, err := os.ReadFile(filepath.Join(*root, filepath.FromSlash(path)))
			if err != nil || !bytes.Equal(current, files[path]) {
				outdated = append(outdated, path)
			}
		}
		outdated = append(outdated, stale...)
		for _, path := range outdated {
			fmt.Fprintln(stderr, "api-map: generated file out of date:", path)
		}
		if len(outdated) > 0 {
			return 1
		}
		fmt.Fprintf(stdout, "generated PHP is current: %d files\n", len(files))
		return 0
	}
	for _, path := range paths {
		if err := model.WriteAtomic(filepath.Join(*root, filepath.FromSlash(path)), files[path]); err != nil {
			fmt.Fprintln(stderr, "api-map:", err)
			return 1
		}
	}
	for _, path := range stale {
		if err := os.Remove(filepath.Join(*root, filepath.FromSlash(path))); err != nil {
			fmt.Fprintln(stderr, "api-map:", err)
			return 1
		}
	}
	fmt.Fprintf(stdout, "generated %d files, removed %d stale\n", len(files), len(stale))
	return 0
}

func effectiveContract(mapPath, overlayDir string, stderr io.Writer) (effective.Result, bool) {
	raw, err := os.ReadFile(mapPath)
	if err != nil {
		fmt.Fprintln(stderr, "api-map:", err)
		return effective.Result{}, false
	}
	m, err := model.DecodeMap(raw)
	if err != nil {
		fmt.Fprintln(stderr, "api-map:", err)
		return effective.Result{}, false
	}
	set, err := overlay.Load(overlayDir)
	if err != nil {
		fmt.Fprintln(stderr, "api-map: overlay:", err)
		return effective.Result{}, false
	}
	problems := overlay.Validate(set)
	result, err := effective.Build(m, set)
	if err != nil {
		fmt.Fprintln(stderr, "api-map:", err)
		return effective.Result{}, false
	}
	problems = append(problems, result.Problems...)
	for _, problem := range problems {
		fmt.Fprintln(stderr, "api-map: overlay:", problem)
	}
	return result, len(problems) == 0
}

// staleGenerated lists generated PHP files (carrying the marker) that the
// current render no longer produces; hand-written files are never listed.
func staleGenerated(root string, files map[string][]byte) ([]string, error) {
	var stale []string
	for _, dir := range []string{"src/Api/Uapi", "src/Api/Whm"} {
		err := filepath.WalkDir(filepath.Join(root, filepath.FromSlash(dir)), func(path string, d fs.DirEntry, err error) error {
			if err != nil {
				if errors.Is(err, fs.ErrNotExist) {
					return nil
				}
				return err
			}
			if d.IsDir() || !strings.HasSuffix(path, ".php") {
				return nil
			}
			relative, err := filepath.Rel(root, path)
			if err != nil {
				return err
			}
			relative = filepath.ToSlash(relative)
			if _, current := files[relative]; current {
				return nil
			}
			content, err := os.ReadFile(path)
			if err != nil {
				return err
			}
			if bytes.Contains(content, []byte(phpgen.Marker)) {
				stale = append(stale, relative)
			}
			return nil
		})
		if err != nil {
			return nil, err
		}
	}
	sort.Strings(stale)
	return stale, nil
}
